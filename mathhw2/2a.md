# 作业 2A：数值积分方法比较

## 一、实验目的

在 MWORKS 中分别实现复合梯形公式和复合辛普森公式，计算定积分
$I=\int_0^1\sqrt{x}\ln x\,\mathrm{d}x$，通过改变步长
$h$，比较两种求积公式的数值误差，观察误差随步长变化的规律，并结合函数的光滑性分析实际精度及步长过小时的计算表现。

## 二、理论基础与公式推导

### 2.1 精确积分值

令 $f(x)=\sqrt{x}\ln x$。当 $x\to0^+$
时，$\sqrt{x}\ln x\to0$，因此定义
$f(0)=0$，可使函数在 $[0,1]$ 上连续。对积分使用分部积分，取
$u=\ln x$、$\mathrm{d}v=x^{1/2}\mathrm{d}x$，则
$\mathrm{d}u=x^{-1}\mathrm{d}x$、$v=\frac{2}{3}x^{3/2}$。于是

$$
\begin{aligned}
I&=\int_0^1x^{1/2}\ln x\,\mathrm dx\\
&=\left.\frac{2}{3}x^{3/2}\ln x\right|_0^1-\frac{2}{3}\int_0^1x^{1/2}\,\mathrm dx\\
&=0-\left.\frac{4}{9}x^{3/2}\right|_0^1=-\frac{4}{9}.
\end{aligned}

$$

因此，后续计算以 $I=-4/9$ 作为精确值。

### 2.2 复合梯形公式

在区间 $[a,b]$ 上，用端点 $(a,f(a))$ 和 $(b,f(b))$ 构造一次插值多项式
$P_1(x)=f(a)\frac{b-x}{b-a}+f(b)\frac{x-a}{b-a}$。对该多项式积分可得
$\int_a^bP_1(x)\,\mathrm{d}x=\frac{b-a}{2}[f(a)+f(b)]$，即单区间梯形公式
$\int_a^bf(x)\,\mathrm{d}x\approx\frac{b-a}{2}[f(a)+f(b)]$。

将 $[a,b]$ 等分为 $n$ 个小区间，步长为 $h=(b-a)/n$，节点为
$x_i=a+ih$。在每个小区间上使用梯形公式并求和，内部节点会出现两次，首末节点各出现一次，得到复合梯形公式

$$
I_T(h)=h\left[\frac{1}{2}f(x_0)+\sum_{i=1}^{n-1}f(x_i)+\frac{1}{2}f(x_n)\right].

$$

本题区间为 $[0,1]$，且 $f(0)=f(1)=0$，所以可简化为
$I_T(h)=h\sum_{i=1}^{n-1}\sqrt{ih}\ln(ih)$，其中
$h=1/n$。

对于 $f\in C^2[a,b]$，复合梯形公式的误差为
$I-I_T(h)=-\frac{(b-a)h^2}{12}f''(\xi)$，因此在相应光滑性条件下具有二阶精度。对本题，$f'(x)=\frac{\ln x+2}{2\sqrt{x}}$，$f''(x)=-\frac{\ln x}{4x^{3/2}}$。由于
$f''(x)$ 在 $x\to0^+$
时无界，经典误差定理的条件不满足，实际收敛阶需要由数值结果观察。

### 2.3 复合辛普森公式

在 $[a,b]$ 上取三个等距节点
$x_0=a$、$x_1=(a+b)/2$、$x_2=b$，用二次拉格朗日插值多项式 $P_2(x)$ 近似
$f(x)$。对三个拉格朗日基函数积分，其系数分别为
$1/3$、$4/3$、$1/3$，从而得到单组辛普森公式

$$
\int_a^bf(x)\,\mathrm{d}x\approx\frac{b-a}{6}\left[f(a)+4f\left(\frac{a+b}{2}\right)+f(b)\right].

$$

将区间等分为 $n$ 个小区间，其中 $n$ 必须为偶数，令
$h=(b-a)/n$、$x_i=a+ih$。每两个相邻小区间组成一组，应用单组公式并求和，可得复合辛普森公式

$$
I_S(h)=\frac{h}{3}\left[f(x_0)+f(x_n)+4\sum_{\substack{i=1\\i\text{为奇数}}}^{n-1}f(x_i)+2\sum_{\substack{i=2\\i\text{为偶数}}}^{n-2}f(x_i)\right].

$$

其中端点权重为 $1$，奇数下标节点权重为 $4$，内部偶数下标节点权重为
$2$。本题两端点函数值均为零，因此只需计算内部节点的加权和。

若 $f\in C^4[a,b]$，复合辛普森公式的误差为
$I-I_S(h)=-\frac{(b-a)h^4}{180}f^{(4)}(\xi)$，通常具有四阶精度。但本题在
$x=0$
处不满足四阶导数连续的条件，因此不能直接将四阶理论精度套用于本题；其实际精度同样由实验数据判断。

## 三、实验方案与误差定义

取 $n=4,8,16,\ldots,4096$，相应步长为 $h=1/n$。所有 $n$
均为偶数，满足复合辛普森公式的使用条件。设两种方法的近似值分别为
$I_T(h)$ 和 $I_S(h)$，其绝对误差定义为 $E_T(h)=|I_T(h)-I|$ 和
$E_S(h)=|I_S(h)-I|$，其中 $I=-4/9$。

为了比较相邻步长下误差的变化，采用实验收敛阶
$p=\frac{\ln(E(h)/E(h/2))}{\ln2}$。若误差近似满足
$E(h)\approx Ch^p$，该公式可用于估计实际收敛阶。

## 四、MWORKS 程序实现

以下代码可在已安装 `TyPlot` 的 MWORKS Julia
环境中运行。程序输出两种方法的近似值、绝对误差和实验收敛阶，并绘制双对数误差曲线。

```julia
using Printf
using TyPlot

# 被积函数在 x = 0 处取连续延拓值，避免计算 log(0)
function f(x)
    if x == 0.0
        return 0.0
    else
        return sqrt(x) * log(x)
    end
end

# 复合梯形公式
function composite_trapezoid(n)
    h = 1.0 / n
    result = 0.5 * f(0.0) + 0.5 * f(1.0)

    for i in 1:(n - 1)
        result += f(i * h)
    end

    return h * result
end

# 复合辛普森公式，n 必须为偶数
function composite_simpson(n)
    if n % 2 != 0
        error("复合辛普森公式要求 n 为偶数")
    end

    h = 1.0 / n
    result = f(0.0) + f(1.0)

    for i in 1:(n - 1)
        if i % 2 == 1
            result += 4.0 * f(i * h)
        else
            result += 2.0 * f(i * h)
        end
    end

    return h * result / 3.0
end

# 精确积分值与绝对误差
I_exact = -4.0 / 9.0
absolute_error(I_approx) = abs(I_approx - I_exact)

n_values = [4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048, 4096]
trap_errors = Float64[]
simpson_errors = Float64[]
h_values = Float64[]

println("精确值 I = ", I_exact)
@printf("%8s %12s %18s %14s %18s %14s\n",
        "n", "h", "梯形近似值", "梯形误差", "辛普森近似值", "辛普森误差")

for n in n_values
    h = 1.0 / n
    I_trap = composite_trapezoid(n)
    I_simpson = composite_simpson(n)
    E_trap = absolute_error(I_trap)
    E_simpson = absolute_error(I_simpson)

    push!(h_values, h)
    push!(trap_errors, E_trap)
    push!(simpson_errors, E_simpson)

    @printf("%8d %12.5e %18.10f %14.5e %18.10f %14.5e\n",
            n, h, I_trap, E_trap, I_simpson, E_simpson)
end

println("\n相邻步长下的实验收敛阶")
@printf("%8s %18s %18s\n", "n", "梯形实验阶", "辛普森实验阶")
for k in 2:length(n_values)
    p_trap = log(trap_errors[k - 1] / trap_errors[k]) / log(2.0)
    p_simpson = log(simpson_errors[k - 1] / simpson_errors[k]) / log(2.0)
    @printf("%8d %18.6f %18.6f\n", n_values[k], p_trap, p_simpson)
end

# 双对数误差图
TyPlot.figure()
TyPlot.loglog(h_values, trap_errors, "o-", label="Composite Trapezoid")
TyPlot.hold("on")
TyPlot.loglog(h_values, simpson_errors, "s-", label="Composite Simpson")
TyPlot.xlabel("Step size h")
TyPlot.ylabel("Absolute error")
TyPlot.title("Quadrature Error versus Step Size")
TyPlot.legend()
TyPlot.grid(true)
```

程序中将 $x=0$ 处的函数值单独设为 $0$，避免出现
$\ln0$；两种求积公式分别按各自节点权重累加函数值。双对数图以步长
$h$
为横坐标、绝对误差为纵坐标，可直观比较两种方法的误差水平和下降趋势。由于
$h$ 从大到小排列，图中的横坐标会由右向左减小，这是正常现象。

## 六、结果分析

### 6.1 步长对误差的影响

从表中可以看到，随着 $n$ 增大、步长 $h=1/n$
减小，两种方法的绝对误差均持续下降。例如，当 $n=4$
时，梯形公式和辛普森公式的绝对误差分别约为 $8.63\times10^{-2}$
和 $4.87\times10^{-2}$；当 $n=4096$ 时，误差分别下降到约
$7.98\times10^{-6}$ 和
$3.63\times10^{-6}$。这说明增加子区间数量能够改善本题的求积结果。

### 6.2 两种求积公式的精度比较

在表列的所有步长下，辛普森公式的绝对误差都小于梯形公式，说明在本次实验范围内，辛普森公式给出的积分近似值更准确。对足够光滑的函数，复合梯形公式通常具有二阶精度，复合辛普森公式通常具有四阶精度；但本题的
$f''(x)=-\ln x/(4x^{3/2})$ 在 $x=0$
附近无界，经典误差阶定理所要求的光滑性条件不成立。因此，应根据实验收敛阶分析本题的实际误差变化，而不能仅凭公式名称认定辛普森公式在本题中具有四阶收敛。

实验收敛阶显示，随着 $n$ 增大，两种方法的估计阶数逐步上升，但在 $n=2048$
和 $n=4096$ 之间，梯形公式的实验阶约为 $1.397$，辛普森公式约为
$1.412$。两者均明显低于光滑函数情况下常见的二阶和四阶理论阶数，体现了端点处高阶导数不连续对误差行为的影响。

### 6.3 是否存在使精度不再改善的最小步长？

步长减小会降低离散求积带来的截断误差，但计算机使用有限精度浮点数，舍入误差会随函数计算和累加过程产生。随着节点数增多，求和次数也增加，因此总误差不仅由截断误差决定，还会受到舍入误差和累积误差影响。实际计算中可能出现误差下降变慢、趋于停滞甚至增大的情况。

严格来说，不存在一个对所有问题都适用的固定"最小步长"。对于给定函数、求积方法和浮点精度，可能存在使总误差较小的步长范围。当前实验计算到
$n=4096$
时，两种方法的误差仍在下降，因此现有结果尚未显示精度停滞，也不能据此确定最优步长。若需要进一步观察，可将
$n$ 扩展至 $8192$、$16384$、$32768$
等，并比较误差是否继续下降；当误差下降幅度明显变小或开始增大时，再结合浮点舍入误差讨论步长的影响。

## 七、实验结论

本实验在 MWORKS 中实现了复合梯形公式和复合辛普森公式，并计算了定积分
$I=\int_0^1\sqrt{x}\ln x\,\mathrm{d}x=-4/9$。实验结果表明，在所测试的步长范围内，随着步长减小，两种方法的绝对误差均持续下降，且辛普森公式的误差始终小于梯形公式。由于被积函数在积分区间左端点处不满足经典误差阶定理所要求的高阶光滑性条件，实际收敛阶与光滑函数情形下的常见理论阶数存在差异。另一方面，步长并非越小越好；当步长足够小时，浮点舍入误差和累积误差可能限制精度的进一步提高。选择步长时，应综合考虑截断误差、舍入误差和计算成本。
