# PDF 导出脚本使用说明

`test.py` 将 `paper1a.md` 转换为 LaTeX，再自动调用 XeLaTeX 编译两次，生成带公式、图片、代码和页码的 PDF。只需要 Python 和 TeX Live，不需要额外安装 Python 包。

## 日常运行

保存修改后的 `paper1a.md`，在 PowerShell 中运行：

```powershell
cd "D:\学习\研一\数学"
python .\tmp\pdfs\test.py
```

生成的 PDF 位于：

```text
D:\学习\研一\数学\output\pdf\paper1a.pdf
```

再次运行会更新同名 PDF。若阅读器锁定文件，先关闭 PDF，再重新运行。脚本只读取 Markdown 和图片，不修改这些源文件，也不执行 Markdown 内的 Julia 程序。

## 目录结构

```text
数学/
├─ paper1a.md
├─ 1a.png
├─ n10.png
├─ n20.png
├─ tmp/
│  └─ pdfs/
│     ├─ test.py
│     └─ 使用说明.md
└─ output/
   └─ pdf/
      └─ paper1a.pdf
```

默认项目目录由脚本的 `Path(__file__).resolve().parents[2]` 确定，因此请将脚本保持在 `tmp/pdfs/` 下。Markdown 中的图片路径相对于 Markdown 所在目录解析。

也可以在其他工作目录使用完整路径运行：

```powershell
python "D:\学习\研一\数学\tmp\pdfs\test.py"
```

## 常用选项

指定另一份输出文件，保留原来的 PDF：

```powershell
python .\tmp\pdfs\test.py --output ".\output\pdf\paper1a_新版.pdf"
```

如果终端找不到 `xelatex`，指定本机的安装路径：

```powershell
python .\tmp\pdfs\test.py --xelatex "C:\texlive\2026\bin\windows\xelatex.exe"
```

只生成 LaTeX 文件，方便查看或手动调整：

```powershell
python .\tmp\pdfs\test.py --tex-only
```

此时文件保存在 `tmp/pdfs/paper1a.tex`。通常修改 Markdown 或脚本后重新导出即可；脚本每次运行都会重新生成 `.tex`，覆盖其中的手工改动。

保持代码的原始换行：

```powershell
python .\tmp\pdfs\test.py --no-compact-code
```

查看全部参数：

```powershell
python .\tmp\pdfs\test.py --help
```

也支持 `--source "文件路径.md"` 指定输入文件；封面标题、页眉、作业名称仍来自脚本的 `preamble`，导出其他作业时需同步修改这些文字。

## 调整版式

脚本的 `preamble` 集中定义了排版参数：

| 设置 | 在脚本中搜索 | 当前值及含义 |
|---|---|---|
| 页边距 | `left=22mm` | 左右 22 mm，上 20 mm，下 21 mm |
| 正文字号与行距 | `\fontsize{10.5}{15.5}` | 正文 10.5 pt，基线间距 15.5 pt |
| 段落间距 | `\setlength{\parskip}{3.5pt}` | 段与段之间增加 3.5 pt |
| 段首缩进 | `\setlength{\parindent}{2em}` | 缩进两个汉字宽度 |
| 公式上下间距 | `abovedisplayskip`、`belowdisplayskip` | 独立公式与正文之间的距离 |
| 代码字号与行距 | `\fontsize{8.5}{10.7}` | 代码字号 8.5 pt，基线间距 10.7 pt |
| 图像宽度 | `width='0.99'` | 题目图片占正文宽度的 99%，其他图片占 70% |
| 标题与页眉 | `preamble` 中的中文文字 | 修改报告标题、课程名称和作业编号 |

修改后保存脚本，再执行日常运行命令即可。该转换器针对当前作业使用的 Markdown 格式，支持二至四级标题、段落、行内及独立公式、代码块、有序列表、图片和简单表格。

## 编译中间文件

`tmp/pdfs/` 下的 `.tex`、`.aux`、`.log`、`.out`、中间 PDF 和 `.compile-1.txt`、`.compile-2.txt` 是编译文件。出现错误时，终端会显示对应日志路径。

运行脚本不需要手动执行两次 XeLaTeX。脚本已经包含两次编译，用于正确生成总页数。完成后可删除这些中间文件，但请保留 `test.py` 和本说明。
